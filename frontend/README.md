# Efficient Contextualized History Orchestrator Frontend

React + Tailwind UI for the Efficient Contextualized History Orchestrator project.

## What this gives you
- A polished landing/dashboard-style interface
- Project-aligned colors that match the project identity
- A clean, privacy-first visual language
- Ready to connect to backend retrieval and ingestion APIs

## Structure
- `src/App.jsx` - main landing page UI
- `src/index.css` - global styles and Tailwind setup
- `tailwind.config.js` - theme tokens
- `vite.config.js` - Vite React setup

## Run locally
```bash
npm install
npm run dev
```

## Notes
This is a starter frontend. It is intentionally lightweight so you can connect it to the backend and expand it into a full dashboard, query interface, or analytics view.
